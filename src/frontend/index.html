AgriVision PestGuard runs a Vision Transformer trained on the IP102 insect pest dataset to classify the pest present in an image and highlight, via Grad-CAM, the image regions that most influenced the prediction. This is an image-level classifier with an explanation heatmap — it does not draw object-detection bounding boxes.
